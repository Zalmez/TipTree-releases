# Tip Tree

A Christmas tree overlay for OBS that fills with the names of people who tip.

## Install

1. Download `TipTree-win-Setup.exe` from the [latest release](https://github.com/Zalmez/TipTree-releases/releases/latest).
2. Run it. Windows SmartScreen warns because the installer is not signed: choose **More info**, then **Run anyway**.
3. Tip Tree starts in the notification area (system tray) and opens its setup page in your browser.

It installs for your user only, with no admin prompt, and updates itself from this page.

## Uninstall

Windows Settings, Apps, Installed apps, Tip Tree, Uninstall.
